## 1) Faça um programa que receba três notas de um aluno, calcule e mostre a média aritmética e a mensagem constante na tabela a seguir. Aos alunos que ficaram para exame, calcule e mostre a nota que deverão tirar para serem aprovados, considerando que a média exigida é 6,0.

| MÉDIA ARITMÉTICA | MENSAGEM |
| :--- | :--- |
| 0 ≤ MÉDIA < 3 | REPROVADO |
| 3 ≤ MÉDIA < 7 | EXAME |
| 7 ≤ MÉDIA ≤ 10 | APROVADO |

```text
ALGORITMO

DECLARE N1, N2, N3, MEDIA, EXAME NUMERICO;

ESCREVA "INFORME AS TRES NOTAS:";
LEIA N1, N2, N3;

MEDIA <- (N1 + N2 + N3) / 3;

ESCREVA "A MEDIA E: ", MEDIA;

SE MEDIA < 3 ENTÃO INÍCIO
    ESCREVA "REPROVADO";
FIM
SENÃO SE MEDIA < 7 ENTÃO INÍCIO
    ESCREVA "EXAME";
    EXAME <- 12 - MEDIA;
    ESCREVA "A NOTA NECESSARIA NO EXAME E: ", EXAME;
FIM
SENÃO INÍCIO
    ESCREVA "APROVADO";
FIM

FIM_ALGORITMO
```

## 6) Faça um programa que receba o salário inicial de um funcionário, calcule e mostre o novo salário, acrescido de bonificação e de auxílio escola.

| SALÁRIO | BONIFICAÇÃO |
| :--- | :--- |
| Até 500,00 reais | 5/100 do salário |
| Entre 500,00 e 1200,00 reais | 12/100 do salário |
| acima de 1200,00 reais | sem bonificação |

| SALÁRIO | AUXÍLIO ESCOLA |
| :--- | :--- |
| Até 600,00 reais | 150,00 reais |
| acima de 600,00 reais | 100,00 reais |

```text
ALGORITMO

DECLARE SAL, BON, AUX, NOVO NUMERICO;

ESCREVA "INFORME O SALARIO:";
LEIA SAL;

SE SAL <= 500 ENTÃO INÍCIO
    BON <- SAL * 0.05;
FIM
SENÃO SE SAL <= 1200 ENTÃO INÍCIO
    BON <- SAL * 0.12;
FIM
SENÃO INÍCIO
    BON <- 0;
FIM

SE SAL <= 600 ENTÃO INÍCIO
    AUX <- 150;
FIM
SENÃO INÍCIO
    AUX <- 100;
FIM

NOVO <- SAL + BON + AUX;

ESCREVA "O NOVO SALARIO E: ", NOVO;

FIM_ALGORITMO
```

## 7) Um mercadinho deseja reajustar os preços de seus produtos usando o seguinte critério: o produto poderá ter seu preço aumentado ou diminuído. Para o preço ser alterado, o produto deve preencher pelo menos um dos requisitos a seguir:

| VENDA MÉDIA MENSAL | PREÇO ATUAL (REAIS) | % DE AUMENTO | % DE DIMINUIÇÃO |
| :--- | :--- | :--- | :--- |
| < 500 | < 30,00 | 10 | - |
| >= 500 e < 1200 | >= 30,00 e < 80,00 | 15 | - |
| >= 1200,00 | >= 80,00 | - | 20 |

```text
ALGORITMO

DECLARE VENDA, PRECO, NOVO NUMERICO;

ESCREVA "INFORME A VENDA MEDIA MENSAL E O PRECO ATUAL:";

SE VENDA < 500 E PRECO < 30 ENTÃO INÍCIO

FIM
SENÃO SE VENDA >= 500 E VENDA < 1200 E PRECO >= 30 E PRECO < 80 ENTÃO INÍCIO
    NOVO <- PRECO + (PRECO * 0.15);
FIM
SENÃO SE VENDA >= 1200 E PRECO >= 80 ENTÃO INÍCIO
    NOVO <- PRECO - (PRECO * 0.20);
FIM
SENÃO INÍCIO
    NOVO <- PRECO;
FIM

ESCREVA "O NOVO PRECO E: ", NOVO;

FIM_ALGORITMO
```

## 8) Dados três valores X, Y e Z, verifique se eles podem ser os comprimentos dos lados de um triângulo e, se forem verifique se é um triângulo equilátero, isóscele ou escaleno. Se eles não formarem um triângulo, escreva uma mensagem. Considere que:
a) o comprimento de cada lado de um triângulo é menor que soma dos outros dois lados;
b) chama-se equilátero o triângulo que tem três lados iguais;
c) denomina-se isósceles o triângulo que tem o comprimento de dois lados iguais;

```text
ALGORITMO

DECLARE X, Y, Z NUMERICO;

ESCREVA "INFORME OS TRES LADOS DO TRIANGULO:";
LEIA X, Y, Z;

SE X < Y + Z E Y < X + Z E Z < X + Y ENTÃO INÍCIO
    SE X = Y E Y = Z ENTÃO INÍCIO
        ESCREVA "EQUILATERO";
    FIM
    SENÃO SE X = Y OU X = Z OU Y = Z ENTÃO INÍCIO
        ESCREVA "ISOSCELES";
    FIM
    SENÃO INÍCIO
        ESCREVA "ESCALENO";
    FIM
FIM
SENÃO INÍCIO
    ESCREVA "NAO FORMA UM TRIANGULO";
FIM

FIM_ALGORITMO
```

## 9) Faça um programa que receba a medida de um ângulo em graus, calcule e mostre o quadrante em que se localiza, reduzindo ângulos maiores que 360° ou menores que -360° e mostrando o número de voltas e o sentido.

```text
ALGORITMO

DECLARE ANGULO, VOLTAS NUMERICO;

ESCREVA "INFORME O ANGULO:";
LEIA ANGULO;

VOLTAS <- INT(ABS(ANGULO) / 360);

SE ANGULO >= 0 ENTÃO INÍCIO
    ESCREVA "SENTIDO ANTI-HORARIO";
FIM
SENÃO INÍCIO
    ESCREVA "SENTIDO HORARIO";
FIM

ANGULO <- ANGULO MOD 360;

SE ANGULO < 0 ENTÃO INÍCIO
    ANGULO <- ANGULO + 360;
FIM

SE ANGULO > 0 E ANGULO < 90 ENTÃO INÍCIO
    ESCREVA "1O QUADRANTE";
FIM
SENÃO SE ANGULO > 90 E ANGULO < 180 ENTÃO INÍCIO
    ESCREVA "2O QUADRANTE";
FIM
SENÃO SE ANGULO > 180 E ANGULO < 270 ENTÃO INÍCIO
    ESCREVA "3O QUADRANTE";
FIM
SENÃO SE ANGULO > 270 E ANGULO < 360 ENTÃO INÍCIO
    ESCREVA "4O QUADRANTE";
FIM
SENÃO INÍCIO
    ESCREVA "O ANGULO ESTA SOBRE UM EIXO";
FIM

ESCREVA "NUMERO DE VOLTAS = ", VOLTAS;

FIM_ALGORITMO
```
