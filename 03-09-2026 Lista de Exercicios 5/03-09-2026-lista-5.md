# Lista de Exercícios 5

1) Cada degrau de uma escada tem X de altura. Faça um programa que receba essa *altura* e a *altura que o usuário deseja alcançar* subindo a escada, calcule e mostre quantos degraus ele deverá subir para atingir seu objetivo, sem se preocupar com a altura do usuário. Todas as medidas fornecidas devem estar em metros.

```text
ALGORITMO
DECLARE ALTURA_DEGRAU, ALTURA_ALCANCAR, QTD_DEGRAUS NUMERICO; 

ESCREVA "INFORME A ALTURA DO DEGRAU E A ALTURA QUE VOCE DESEJA ALCANÇAR:";
LEIA ALTURA_DEGRAU, ALTURA_ALCANCAR;

QTD_DEGRAUS = ALTURA_ALCANCAR / ALTURA_DEGRAU

ESCREVA "A QUANTIDADE DE DEGRAUS NECESSARIA PARA ATINGIR O OBJETIVO É", QTD_DEGRAUS

FIM_ALGORITMO
```

2) Faça um programa que receba a *medida do ângulo (em graus)* formado por uma escada apoiada no chão e encostada na parede e a altura da parede onde está a ponta da escada. Calcule e mostre a medida dessa escada.
Observação: as funções trigonométricas implementadas nas linguagens de programação trabalham com medidas de ângulos em radianos.

```text
ALGORITMO
DECLARE ANGULO, ALTURA_PAREDE, MEDIDA_ESCADA, ANGULO_RADIANOS NUMERICO;

ESCREVA "INFORME O ANGULO EM GRAUS E A ALTURA DA PAREDE:";
LEIA ANGULO, ALTURA_PAREDE;

ANGULO_RADIANOS = ANGULO * (3.14159 / 180);

MEDIDA_ESCADA = ALTURA_PAREDE / SENO(ANGULO_RADIANOS);

ESCREVA "A MEDIDA DESSA ESCADA É ", MEDIDA_ESCADA;

FIM_ALGORITMO
```

3) Uma pessoa deseja pregar um quadro em uma parede. Faça um programa para *calcular e mostrar a que distância a escada deve estar da parede*. A pessoa deve fornecer o *tamanho da escada* e a *altura em que deseja pregar o quadro*.
Lembre-se de que o *tamanho da escada deve ser maior que a altura que se deseja alcançar*.

```text
ALGORITMO
DECLARE TAMANHO_ESCADA, ALTURA_QUADRO, DISTANCIA_ESCADA NUMERICO;

ESCREVA "INFORME O TAMANHO DA ESCADA E A ALTURA QUE DESEJA PREGAR O QUADRO:";
LEIA TAMANHO_ESCADA, ALTURA_QUADRO;

SE TAMANHO_ESCADA <= ALTURA_QUADRO 
ENTÃO INÍCIO
    ESCREVA "O TAMANHO DA ESCADA DEVE SER MAIOR QUE A ALTURA QUE SE DESEJA ALCANÇAR."
FIM
SENÃO INÍCIO
    DISTANCIA_ESCADA = RAIZ_QUADRADA((TAMANHO_ESCADA * TAMANHO_ESCADA) - (ALTURA_QUADRO * ALTURA_QUADRO))
    ESCREVA "A DISTANCIA DA ESCADA ATE A PAREDE DEVE SER DE: ", DISTANCIA_ESCADA
FIM

FIM_ALGORITMO
```

4) Faça um programa que receba um número real, encontre e mostre:
a) a parte inteira desse número;
b) a parte fracionária desse número;
c) o arredondamento desse número.

```text

DECLARE NUMERO, PARTE_FRACIONARIA REAL; 
DECLARE PARTE_INTEIRA, ARREDONDAMENTO INTEIRO;

ESCREVA "INFORME UM NUMERO REAL (EX: 4.75):"

PARTE_INTEIRA = INTEIRO(NUMERO)

PARTE_FRACIONARIA = NUMERO - PARTE_INTEIRA

ARREDONDAMENTO = ARREDONDA(NUMERO)

ESCREVA "PARTE INTEIRA: ", PARTE_INTEIRA;
ESCREVA "PARTE FRACIONÁRIA: ", PARTE_FRACIONARIA;
ESCREVA "ARREDONDAMENTO: ", ARREDONDAMENTO;
FIM_ALGORITMO
```

6) Faça um programa que receba o salário base e o tempo de serviço de um funcionário. Calcule e mostre:

O imposto, conforme a tabela a seguir.

| SALÁRIO BASE        | % SOBRE O SALÁRIO BASE |
| :------------------ | :--------------------- |
| < 200               | ISENTO                 |
| 200 ≤ SALÁRIO ≤ 450 | 3%                     |
| 450 < SALÁRIO < 700 | 8%                     |
| > 700               | 12%                    |

A gratificação, de acordo com a tabela a seguir.

| SALÁRIO BASE   | TEMPO DE SERVIÇO    | GRATIFICAÇÃO |
| :------------- | :------------------ | :----------- |
| SUPERIOR A 500 | ATÉ 3 ANOS          | 20           |
| SUPERIOR A 500 | MAIS DE 3 ANOS      | 30           |
| ATÉ 500        | ATÉ 3 ANOS          | 23           |
| ATÉ 500        | ENTRE 3 E 6 ANOS    | 35           |
| ATÉ 500        | DE 6 ANOS PARA CIMA | 33           |

O salário líquido, ou seja, salário base menos imposto mais gratificação.

A categoria, que está na tabela a seguir.

| SALÁRIO LÍQUIDO  | CLASSIFICAÇÃO |
| :--------------- | :------------ |
| ATÉ 350          | A             |
| ENTRE 350 E 600  | B             |
| DE 600 PARA CIMA | C             |

```text
ALGORITMO

DECLARE SALARIO_BASE, TEMPO_SERVICO, IMPOSTO, GRATIFICACAO, SALARIO_LIQUIDO NUMERICO;

ESCREVA "INFORME O SALÁRIO BASE E O TEMPO DE SERVIÇO:"
LEIA SALARIO_BASE, TEMPO_SERVICO;

SE SALARIO_BASE < 200
ENTÃO INÍCIO
    IMPOSTO = 0;
FIM
SENÃO SE SALARIO_BASE <= 450
ENTÃO INÍCIO
    IMPOSTO = SALARIO_BASE * 0.03;
FIM
SENÃO SE SALARIO_BASE < 700
ENTÃO INÍCIO
    IMPOSTO = SALARIO_BASE * 0.08;
FIM
SENÃO
INÍCIO
    IMPOSTO = SALARIO_BASE * 0.12;
FIM


SE SALARIO_BASE > 500 E TEMPO_SERVICO <= 3
ENTÃO INÍCIO
    GRATIFICACAO = 20;
FIM
SENÃO SE SALARIO_BASE > 500 E TEMPO_SERVICO > 3
ENTÃO INÍCIO
    GRATIFICACAO = 30;
FIM
SENÃO SE SALARIO_BASE <= 500 E TEMPO_SERVICO <= 3
ENTÃO INÍCIO
    GRATIFICACAO = 23;
FIM
SENÃO SE SALARIO_BASE <= 500 E TEMPO_SERVICO > 3 E TEMPO_SERVICO < 6
ENTÃO INÍCIO
    GRATIFICACAO = 35;
FIM
SENÃO
INÍCIO
    GRATIFICACAO = 33;
FIM


SALARIO_LIQUIDO = SALARIO_BASE - IMPOSTO + GRATIFICACAO;

ESCREVA "O IMPOSTO APLICADO É ", IMPOSTO;
ESCREVA "A GRATIFICAÇÃO APLICADA É ", GRATIFICACAO;
ESCREVA "O SALÁRIO LÍQUIDO É ", SALARIO_LIQUIDO;

FIM_ALGORITMO
```

7) Faça um programa que receba:
- o código do *estado de origem da carga de um caminhão*, supondo que a digitação do código do estado seja sempre válida, isto é, um número inteiro entre *1 e 5*;
- o *peso da carga* do caminhão em toneladas;
- o *código da carga*, supondo que a digitação do código seja sempre válida, isto é, um número inteiro entre *10 e 40*.

| CÓDIGO DO ESTADO | IMPOSTO |
| :--------------- | :------ |
| 1                | 35%     |
| 2                | 25%     |
| 3                | 15%     |
| 4                | 5%      |
| 5                | ISENTO  |

| CÓDIGO DA CARGA | PREÇO POR QUILO |
| :-------------- | :-------------- |
| 10 A 20         | 100             |
| 21 A 30         | 250             |
| 31 A 40         | 340             |

```text
LEIA PESO_CARGA;

ESCREVA "INFORME O CÓDIGO DA CARGA (ENTRE 10 E 40):";
LEIA CODIGO_CARGA;


SE CODIGO_ESTADO == 1
ENTÃO INÍCIO
    IMPOSTO = 0.35;
FIM
SENÃO SE CODIGO_ESTADO == 2
ENTÃO INÍCIO
    IMPOSTO = 0.25;
FIM
SENÃO SE CODIGO_ESTADO == 3
ENTÃO INÍCIO
    IMPOSTO = 0.15;
FIM
SENÃO SE CODIGO_ESTADO == 4
ENTÃO INÍCIO
    IMPOSTO = 0.05;
FIM
SENÃO

FIM


SE CODIGO_CARGA >= 10 E CODIGO_CARGA <= 20

    PRECO_QUILO = 100;
FIM

    PRECO_QUILO = 250;
FIM
SENÃO
INÍCIO
    PRECO_QUILO = 340;
FIM

ESCREVA "O PREÇO POR QUILO É ", PRECO_QUILO;
```

9) Faça um programa para resolver equações do 2º grau.
```text
ALGORITMO

DECLARE A, B, C, DELTA, X1, X2 NUMERICO;

ESCREVA "INFORME O VALOR DE A:";
LEIA A;

ESCREVA "INFORME O VALOR DE B:";
LEIA B;

ESCREVA "INFORME O VALOR DE C:";
LEIA C;


DELTA = B * B - 4 * A * C;


SE DELTA < 0
ENTÃO INÍCIO

    ESCREVA "A EQUAÇÃO NÃO POSSUI RAÍZES REAIS.";

FIM

SENÃO SE DELTA == 0
ENTÃO INÍCIO

    X1 = -B / (2 * A);

    ESCREVA "A EQUAÇÃO POSSUI UMA RAIZ REAL.";
    ESCREVA "A RAIZ É ", X1;

FIM

SENÃO
INÍCIO

    X1 = (-B + RAIZ(DELTA)) / (2 * A);
    X2 = (-B - RAIZ(DELTA)) / (2 * A);

    ESCREVA "A EQUAÇÃO POSSUI DUAS RAÍZES REAIS.";
    ESCREVA "X1 = ", X1;
    ESCREVA "X2 = ", X2;

FIM

FIM_ALGORITMO
```
